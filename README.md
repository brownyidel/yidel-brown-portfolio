# Yidel Brown Portfolio

A static portfolio website built for a Fiverr freelancer profile.

## Included
- Main portfolio (`index.html`)
- FlowPilot automation dashboard demo
- Northline responsive business website demo
- CleanCSV working browser data-cleaning tool
- YB profile logo
- Responsive CSS and JavaScript

## Important
The featured projects are clearly labeled as demo/portfolio projects. They should not be represented as paid client work.

## Deploy
This is a static website. Upload the whole folder to a static host such as Vercel, Netlify, Cloudflare Pages, or GitHub Pages.

Before publishing:
1. Replace the placeholder Fiverr button in `index.html` with your actual Fiverr profile URL once it is live.
2. Review the wording and make sure every skill listed is one you are comfortable offering.
3. Keep the demo labels visible.
